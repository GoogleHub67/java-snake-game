# java-snake-game

A lightweight, pure Java implementation of the classic retro Snake game. Built completely from scratch with zero external dependencies, frameworks, or engines, this desktop application utilizes Java's native Swing and AWT graphics libraries. It features custom pixel rendering, real-time input handling via key listeners, collision detection, live score tracking, and an integrated automated gameplay loop using a swing execution timer. Perfect for minimalists, students, or anyone wanting to see native Java graphics capability in action without the bulk of heavy build tools.

## 🚀 Getting Started

### Prerequisites
Make sure you have the **Java Development Kit (JDK 11 or higher)** installed on your machine.

### Installation & Execution
You can download, compile, and run this game straight from your terminal in just a few quick commands:

```bash
# 1. Clone the repository
git clone https://github.com/GoogleHub67/java-snake-game

# 2. Navigate into the project folder
cd java-snake-game

# 3. Compile the Java source file
javac snake-game.java

# 4. Run the executable application
java snake-game
```

## 🎮 How to Play
* Use the **Arrow Keys** (`↑`, `↓`, `←`, `→`) to change the snake's direction.
* Eat the **Red Apples** to grow longer and increase your score.
* Avoid crashing into the screen borders or biting your own tail.
* If you lose, press the **Spacebar** to immediately restart the match.

## 🛠️ Built With
* **Java SE** - Core language mechanics.
* **Swing & AWT** - Graphical user interface, canvas painting, and keyboard interactions.
